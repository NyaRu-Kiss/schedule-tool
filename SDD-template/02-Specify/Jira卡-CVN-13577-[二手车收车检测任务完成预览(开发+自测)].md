h3. {color:#de350b}PO需求{color}

评估师在完成检测任务录入后，需要在正式生成并发送检测报告给客户之前，先预览报告的整体样式和内容，确认无误后再生成正式报告。预览功能是一个轻量级的只读视图，不触发任何企微推送，也不生成报告链接，仅供评估师内部核查使用。

预览页面展示的内容与正式报告一致，包括车辆基本信息（VIN、品牌、车系、车型、车牌、里程、首次上牌时间）以及检测结果（仅展示有问题的检测项，即勾选了"有问题"的项，并显示对应的问题照片）。预览页面无"发送"按钮，只有"返回修改"和"生成报告"两个操作入口。

本卡为后端预览接口开发 + 前端预览页面开发 + 自测。

h3. {color:#00875a}用户故事{color}

* 用户/系统: 企业微信二手车 H5（nbms-usedcar-h5）+ project-v-ucm 后端 API

* 行为: 基于 03-经销商收车检测模块 PRD 及技术方案，在 nbms-usedcar-h5 实现检测报告预览页面，在 project-v-ucm 实现 PreviewReport 后端接口，供评估师在生成正式报告前预览报告内容。

* 价值: 让评估师在发送报告给客户前有机会核查报告内容，减少因数据录入错误导致的报告重发情况，提升报告质量。

h3. {color:#ffab00}验收标准{color}

| *前置假设条件* | *业务行为举例* | *期望结果* |
| 检测任务已完成四步骤录入并保存 | 评估师在任务详情页点击"预览报告" | 进入预览页，展示车辆基本信息和检测结果 |
| 检测任务中有多个有问题的检测项 | 评估师查看预览页的检测结果区域 | 仅展示勾选了"有问题"的检测项，每项显示问题描述和对应照片 |
| 检测任务中所有检测项均无问题 | 评估师查看预览页 | 检测结果区域显示"所有检测项均正常" |
| 评估师发现预览内容有误 | 评估师点击"返回修改" | 返回检测任务编辑页，可重新修改检测数据 |
| 预览内容确认无误 | 评估师点击"生成报告" | 跳转至报告生成流程（CVN-13578），触发正式报告生成 |
| 预览页面 | 评估师尝试分享预览页链接给他人 | 预览页需要评估师登录态，他人无法直接访问（与正式报告的客户端链接区分） |
| 后端接口调用 | 前端调用 PreviewReport 接口 | 接口不修改数据库任何字段，不生成 ReportToken，不调用企微接口 |
