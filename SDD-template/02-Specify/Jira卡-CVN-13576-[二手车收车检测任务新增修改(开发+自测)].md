h3. {color:#de350b}PO需求{color}

二手车评估师在完成收车检测时，需要录入大量结构化信息，包括客户基本信息、车辆照片、重点检测项以及按骨架/外观/内饰三个维度的详细检测项。目前缺乏一套标准化的录入工具，导致检测信息分散、不规范，难以形成统一的检测报告。

本次需求是在企微 H5 中实现检测任务的新增和修改功能，采用四步骤表单设计：第一步录入基本信息（客户姓名、手机号、车辆信息）；第二步上传基本照片（外观、内饰等基础照片）；第三步录入重点检测项（车辆配件 3 张照片、轮胎左右前后 4 张照片）；第四步完成车辆检测（骨架/外观/内饰三个 Tab，每个检测部位有勾选框，有问题时勾选并拍照）。检测项内容由后端配置表驱动，Fan, Zuoxin 将提供 Excel 表格确认最终检测项。

本卡为后端保存接口开发 + 前端四步骤表单页面开发 + 自测。

h3. {color:#00875a}用户故事{color}

* 用户/系统: 企业微信二手车 H5（nbms-usedcar-h5）+ project-v-ucm 后端 API

* 行为: 基于 03-经销商收车检测模块 PRD 及技术方案，在 nbms-usedcar-h5 实现检测任务新增/修改的四步骤表单，在 project-v-ucm 实现 SaveInspectTask 后端接口，支持检测数据的完整录入和保存。

* 价值: 为评估师提供标准化的检测录入工具，确保检测信息完整、规范，为后续报告生成奠定数据基础。

h3. {color:#ffab00}验收标准{color}

| *前置假设条件* | *业务行为举例* | *期望结果* |
| 评估师进入新增检测任务页 | 评估师在第一步填写客户姓名、手机号，选择车辆信息 | 客户姓名和手机号为必填项，手机号格式校验（11位数字），车辆信息从现有车源中选择 |
| 第一步填写完成 | 评估师点击"下一步" | 进入第二步基本照片上传页，可上传外观、内饰等基础照片 |
| 进入第三步重点检测 | 评估师上传车辆配件照片 | 配件照片最多上传 3 张；轮胎照片分左前、右前、左后、右后 4 个位置，每个位置上传 1 张 |
| 进入第四步车辆检测 | 评估师切换骨架/外观/内饰 Tab | 各 Tab 下展示对应的检测项列表，每项有勾选框 |
| 某检测项有问题 | 评估师勾选该检测项 | 勾选后出现拍照上传区域，评估师可上传该问题的照片 |
| 四步骤均填写完成 | 评估师点击"保存" | 数据保存成功，返回检测任务列表页，任务状态为"草稿" |
| 已有草稿任务 | 评估师重新进入该任务 | 四步骤表单回显已保存的数据，可继续修改 |
| 保存时网络异常 | 评估师点击"保存"后网络中断 | 前端提示"保存失败，请重试"，数据不丢失 |
