h3. {color:#de350b}PO需求{color}

评估师在预览检测报告确认无误后，需要生成正式的检测报告并通过企微任务推送给自己，以便后续将报告链接转发给客户。报告生成后，系统会为该检测任务生成一个唯一的报告链接，该链接同时适配手机端和 PC 端（通过屏幕宽度自动判断展示对应布局）。

生成报告时，系统需要调用企微的任务接口，将报告链接以任务形式推送给当前评估师，任务内容包含车辆 VIN 和报告链接。评估师接到企微任务后，可将任务中的报告链接复制并发送给客户。报告生成后，任务状态更新为"已发送"。

本卡为后端报告生成接口（含企微任务推送）开发 + 前端报告生成交互开发 + 自测。

h3. {color:#00875a}用户故事{color}

* 用户/系统: 企业微信二手车 H5（nbms-usedcar-h5）+ project-v-ucm 后端 API + 企微任务接口

* 行为: 基于 03-经销商收车检测模块 PRD 及技术方案，在 project-v-ucm 实现 GenerateReport 后端接口（生成 ReportToken、拼接报告 URL、调用企微任务接口），在 nbms-usedcar-h5 实现生成报告的前端交互（展示报告 URL、支持复制）。

* 价值: 打通检测报告从生成到推送的完整链路，确保评估师能够通过企微任务及时获取报告链接，提升报告分发效率。

h3. {color:#ffab00}验收标准{color}

| *前置假设条件* | *业务行为举例* | *期望结果* |
| 检测任务已完成录入，评估师在预览页确认无误 | 评估师点击"生成报告" | 系统生成唯一报告链接，任务状态更新为"已发送"，企微推送任务给评估师 |
| 报告生成成功 | 评估师查看企微任务 | 企微任务内容包含车辆 VIN 和报告链接，评估师可点击链接或复制链接 |
| 报告链接生成后 | 评估师将链接发给手机端客户 | 客户打开链接后展示手机端布局（屏幕宽度 < 768px） |
| 报告链接生成后 | 评估师将链接发给 PC 端客户 | 客户打开链接后展示 PC 端宽屏布局（屏幕宽度 ≥ 768px） |
| 同一检测任务重复点击"生成报告" | 评估师对已生成报告的任务再次点击生成 | 系统重新生成新的 ReportToken，旧链接失效，企微再次推送新任务 |
| 企微任务接口调用失败 | 企微服务不可用时评估师点击生成报告 | 前端提示"报告生成成功，但企微推送失败，请手动复制链接发送给客户"，报告链接仍正常展示 |
| 报告生成后 | 评估师在检测任务列表查看该任务 | 任务状态显示为"已发送" |
