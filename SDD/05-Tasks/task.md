## 统一约束编号

- **C1** 固定链路 `WorkBuddy → MCP → 本地 Agent → 后端 → MySQL`；MCP 只协议适配、转发和透传。
- **C2** Agent 接入部署配置指定的 LLM 做文本理解；确定性逻辑负责排期、时间选择和参数化 SQL。
- **C3** 后端对 Agent 内部 SQL 接口执行服务认证和最终鉴权，并负责业务限制、冲突检查、SQL 白名单校验、事务和幂等；电脑和手机前端及其普通 API 无需认证，打开即可使用，仍执行参数和业务校验。
- **C4** 最多 3 轮完整尝试；每轮可包含查询和创建，冲突后重新查询。
- **C5** 错误响应顶层为 `retryable`，`error` 只含 `code`、`message`。
- **C6** UTC 存储并携带 IANA 时区；默认时长 30 分钟，查询范围受 `SCHEDULE_HORIZON_DAYS` 限制。
- **C7** 仅沿用 `todos`、`scheduled_tasks`、`calendar_events`、`sent_reminders`；禁止通用 SQL 批次绕过业务校验。
- **C8** WorkBuddy 轮询、发送并确认提醒；失败保留可重试状态。
